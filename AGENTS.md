## General

* One logical change per commit
* If changes or or new features are needed on the rustradio crates, the tell the user
* Do not implement anything that should instead be added in the rustradio APIs

## Commit messages

* Max 72 characters per line, for both first line and body
* First line short description
* Further commit message elaborates on why with examples where possible

## Presubmits

NEVER skip presubmits.
